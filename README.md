# Pelota Invernal RD — demo web 3D

Demo independiente y no oficial de béisbol dominicano. Incluye seis equipos, selección de lineup y una escena WebGL con Three.js.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub llamado `pelota-invernal-rd`.
2. Sube `index.html` a la raíz del repositorio y confirma el commit.
3. En **Settings → Pages**, selecciona **Deploy from a branch** y elige **main** y **/(root)**.
4. Accede a `https://TU_USUARIO.github.io/pelota-invernal-rd/`.

Requiere internet para cargar Three.js desde jsDelivr. Probar preferiblemente en Safari actualizado. Las partidas son simplificadas y los rosters contienen nombres y dorsales aportados por el usuario; esta versión no contiene una licencia oficial de LIDOM.
